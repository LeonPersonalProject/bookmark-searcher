# 📚 书签搜索器 - 浏览器扩展

一个简洁高效的浏览器扩展，帮助你快速搜索和访问浏览器书签。采用高密度命令面板式界面，支持完整的键盘导航、文件夹浏览和多种主题模式。

## ✨ 功能特点

### 核心功能
- 🔍 **实时搜索**：输入关键词即时过滤书签（支持防抖优化）
- 🎯 **智能匹配**：支持多关键词、标题、网址、路径和 `domain:` 域名过滤
- 🔤 **模糊搜索**：支持模糊匹配，更容易找到目标书签
- 🈶 **拼音搜索**：中文标题和路径支持拼音及首字母匹配，无需联网
- 🧠 **自适应排序**：结合匹配质量、访问次数和最近使用时间排列结果
- 💡 **高亮显示**：匹配的关键词会被高亮标记
- ⚡ **快速访问**：点击结果即可在新标签页打开
- 📁 **路径显示**：显示书签所在的文件夹位置
- 🎨 **网站图标**：可选择离线占位图标，或按需懒加载外部网站图标
- 📌 **固定书签**：把常用书签固定到首页，减少重复搜索

### 文件夹导航
- 📂 **浏览文件夹**：点击文件夹进入，查看内部书签
- 🔙 **返回导航**：支持返回上一级文件夹
- 🎨 **视觉区分**：文件夹使用独立底色的图标和数量标识，一眼识别
- 📊 **书签计数**：显示每个文件夹包含的书签数量
- 🔍 **文件夹搜索**：搜索时同时显示匹配的文件夹
- 🎯 **明确搜索范围**：在当前文件夹与全部书签之间切换，避免因目录位置漏掉结果

### 智能功能 🆕
- ⏱️ **最近访问**：记录并快速访问最近打开的书签
- 🕐 **搜索历史**：保存搜索记录，快速重复搜索
- 💾 **数据持久化**：自动保存用户偏好和历史记录
- ⚡ **搜索索引**：预先处理标题、网址、路径和域名，减少输入时的重复计算
- 💻 **斜杠命令**：输入 `/` 查看命令，支持补全、选择和执行

### 键盘快捷键
- ⌨️ **完整键盘导航**：无需鼠标即可完成所有操作
- ⌨️ **全局快捷键**：Ctrl/Cmd+Shift+K 快速打开扩展
- ↑↓ **方向键导航**：上下选择书签/文件夹
- 📂 **文件夹跳转**：Ctrl/Cmd+↑↓ 只在文件夹之间循环选择
- ⏎ **Enter 打开**：打开选中的书签或进入文件夹
- ↗️ **Ctrl/Cmd+Enter**：在后台标签页打开选中的书签
- ✏️ **书签操作**：右键或点击更多按钮，编辑、删除或后台打开书签
- ↩️ **目录返回**：空搜索时按 ← 或 Backspace，也可随时按 Alt+←/↑ 返回上一级
- 📄 **快速定位**：Ctrl/Cmd+Home/End 跳到首尾，PageUp/PageDown 翻页选择
- ⎋ **Esc 分级返回**：关闭浮层、清空搜索或返回上一级
- ❔ **快捷键地图**：点击底部“快捷键”，或按 Ctrl/Cmd+/ 查看全部操作
- ⇥ **Tab 导航**：按浏览器标准顺序切换交互控件

### 设计特色
- 🎨 **命令面板布局**：突出搜索操作，并用紧凑列表提高信息密度
- 🌙 **外观模式**：支持跟随系统、浅色和深色模式
- 🍬 **六套配色**：经典紫、糖果色、海盐蓝、抹茶绿、日落橙和黑白灰，可与外观模式自由组合
- 🌈 **语义化配色**：各主题使用独立的焦点、文件夹与状态颜色，保持层级一致
- ✨ **克制动效**：选中和悬停不再引起列表位移，并支持减少动态效果
- 🧭 **路径导航**：通过可点击的面包屑快速返回任意上级目录
- ⚙️ **设置抽屉**：在保留搜索上下文的同时调整偏好

糖果色采用干净白底与草莓粉、葡萄紫、薄荷绿点缀，界面背景使用纯色；所有配色均提供独立的浅色与深色版本，并会自动保存选择。

### 用户体验
- 🦴 **骨架屏**：加载时显示优雅的骨架屏动画 🆕
- 💬 **错误提示**：友好的错误提示和反馈 🆕
- 💡 **快捷键提示**：在底部持续显示常用操作
- ♿ **无障碍支持**：完整的 ARIA 标签、高对比度和强制颜色模式支持 🆕

## 📦 安装方法

### Chrome / Edge / 其他 Chromium 浏览器

1. **打开扩展管理页面**
   - Chrome: 访问 `chrome://extensions/`
   - Edge: 访问 `edge://extensions/`

2. **开启开发者模式**
   - 点击右上角的"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择本项目文件夹 `bookmark-searcher`

4. **完成安装**
   - 扩展安装完成！点击浏览器工具栏中的扩展图标即可使用
   - 建议将扩展固定到工具栏（右键点击扩展图标 → 固定）

### 重新加载扩展

如果更新了代码，需要刷新扩展：
1. 打开扩展管理页面
2. 找到"书签搜索器"扩展
3. 点击刷新图标 🔄

## 🎯 使用指南

### 基础操作

1. **打开扩展**
   - 点击浏览器工具栏中的扩展图标

2. **搜索书签**
   - 在搜索框中输入关键词
   - 多个关键词会同时匹配，例如 `github actions`
   - 使用 `domain:github.com` 只查看指定域名
   - 域名筛选包含该域名及其子域名，不会匹配名称相似的其他网站
   - 中文标题可直接输入拼音或首字母
   - 实时查看匹配的书签列表
   - 匹配的关键词会高亮显示
   - 搜索有结果时默认选中第一项，搜索框保持输入焦点

3. **打开书签**
   - 点击任意书签在新标签页中打开
   - 直接按 Enter 打开首项，按 ↑ / ↓ 切换后再按 Enter 打开其他结果
   - 选中行右侧显示 `↵ 打开`；文件夹显示 `↵ 进入`，按 Enter 进入该文件夹
   - 中文输入法确认候选时只提交文字，再按一次 Enter 才打开结果

### 文件夹导航

1. **识别文件夹**
   - 文件夹带有独立底色的文件夹图标
   - 右侧显示其中包含的书签数量

2. **进入文件夹**
   - 点击文件夹或选中后按 Enter
   - 只显示该文件夹内的内容

3. **返回上一级**
   - 点击顶部路径中的任意上级目录
   - 或在搜索框为空时按 Esc 返回上一级

4. **文件夹内搜索**
   - 进入文件夹后输入关键词
   - 默认搜索当前文件夹及全部子目录，也可切换到全部书签
   - 从结果进入文件夹后返回，会恢复原查询、选中项和滚动位置

### 固定与命令

- 在书签的更多操作菜单中固定或取消固定常用书签，固定项会显示在首页。
- 首页固定卡片右侧的“×”可直接取消固定，也可用 Tab 定位后按 Enter 操作；原书签会保留。
- 同一菜单也可复制完整网址，或定位到书签所在的文件夹。
- 输入 `/` 显示命令，使用 ↑ / ↓ 选择，Tab 补全，Enter 执行。
- `/clear` 清空搜索历史，确认框默认聚焦“清空”；再次按 Enter 确认，Esc 取消。
- `/clear all` 清除搜索历史、最近使用和使用统计；书签、固定项和设置保留。
- `/help` 查看命令与快捷键，`/settings` 打开设置，`/home` 返回根目录，`/back` 返回上一级。
- `/theme system|light|dark`、`/fuzzy on|off` 和 `/favicon on|off` 可直接调整偏好。
- 如果搜索内容本身以 `/` 开头，使用 `//` 搜索字面斜杠，例如 `//docs`。

## 🔧 技术实现

### 技术栈
- **HTML5**：页面结构
- **CSS3**：主题变量、高密度列表布局和轻量动效
- **JavaScript (ES6+)**：核心逻辑
- **Chrome Extensions API**：书签访问和标签页管理

### 核心功能实现

**书签管理**
- 使用 `chrome.bookmarks.getTree()` 获取书签树
- 递归遍历书签树，扁平化处理
- 区分书签和文件夹，分别处理

**搜索功能**
- 实时监听输入框变化
- 使用预处理索引匹配标题、URL、路径、拼音和域名
- 支持多关键词、短语、域名边界过滤和模糊搜索
- 结合匹配质量、使用次数与最近使用时间排序
- 按实际匹配的原文范围高亮，拼音匹配映射回对应中文

**键盘导航**
- 全局变量 `selectedIndex` 追踪选中状态
- 使用独立快捷键映射处理跨平台组合键
- 键盘导航只滚动结果内容区，保持搜索框与页脚位置稳定
- 支持结果循环、文件夹跳转、翻页和父目录返回

**文件夹导航**
- 维护 `currentFolderId` 追踪当前位置
- 动态过滤显示当前文件夹内容
- 根据文件夹父子关系生成可点击的面包屑导航

## 🔒 权限说明

本扩展仅申请了以下权限：
- `bookmarks`：读取、编辑和删除用户明确操作的书签
- `storage`：保存主题、使用偏好、历史和固定书签标识

**隐私说明**：扩展不会把书签、搜索历史或使用记录上传给开发者。主题和偏好保存在 `chrome.storage.sync`，可随浏览器的同步设置同步；搜索历史、最近使用、使用统计及固定书签 ID 保存在 `chrome.storage.local`。拼音匹配完全在本地完成。

关闭“在线网站图标”时使用离线占位图标；开启后会按需向 Google Favicon 服务发送外部网站的域名以获取图标，不发送完整书签网址。IP 地址及可识别的本机、内网域名使用离线图标。图标请求失败会自动回退到占位图标。

## 🧪 开发检查

修改代码后运行：

```bash
bash check.sh
```

该命令会检查运行时与开发检查脚本的 JavaScript 语法、Manifest、HTML/CSS 结构，并运行搜索、键盘、命令、书签、存储、配色和弹窗测试。默认不需要 Playwright。需要生成发布包时运行 `bash build.sh`；打包包含全部运行时模块及拼音数据许可。

可选的真实浏览器界面检查：

```bash
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
bash check.sh --browser
```

Playwright 仅用于开发检查，不进入扩展发布包。也可单独运行 `node scripts/browser-check.cjs`，复用已有工具和本地 Chrome 时可指定：

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
BROWSER_EXECUTABLE=/usr/bin/google-chrome \
BROWSER_CHECK_OUTPUT=/tmp/bookmark-browser-check \
node scripts/browser-check.cjs
```

脚本检查真实 Chromium 的 DOM、原生键盘操作和布局，包括命令补全、清空确认、拼音与搜索范围、域名边界、批量追加、导航恢复、固定/复制/定位、深层面包屑、帮助滚动、失败重试及 12 套明暗主题。截图默认保存在输出中显示的临时目录。

其中 `chrome.bookmarks`、`chrome.storage` 和 `chrome.tabs` 使用注入的测试数据与模拟接口，不代表已完成真实扩展平台的端到端验证。浏览器权限、全局快捷键、真实书签读写、扩展弹窗关闭行为仍需通过“加载已解压的扩展程序”在 Chrome/Edge 中手动检查。

运行只读搜索性能基准：

```bash
node scripts/benchmark.cjs
```

默认使用 1,000、10,000、50,000 个合成书签，报告树遍历与首次索引耗时、各查询的首次耗时，以及随后重复查询的中位数和最大耗时。不会读取真实书签、写文件或访问网络。该结果不包含 Chrome API、弹窗启动和 DOM 渲染时间；浏览器中的实际体验仍需手动检查。

数万条书签的首次拼音查询需要按需建立索引，可能比后续查询明显慢；当前弹窗会话会复用缓存。使用当前文件夹范围可减少一次处理的数据量。实际耗时取决于书签内容与设备，应结合基准和浏览器体验判断。

本地测量结果、查询顺序和测量限制见 [性能测量说明](PERFORMANCE.md)。

GitHub Actions 会在提交和 Pull Request 中执行静态检查与单元测试、验证发布包，并通过独立作业安装开发用 Playwright/Chromium，运行浏览器界面检查并保存截图。打 `v*` 标签时还会校验标签版本与 Manifest 版本一致。

### 扩展无法加载
- 确保文件夹路径正确
- 确保所有文件都在同一个文件夹中
- 检查 manifest.json 是否有语法错误

### 页面显示空白
1. 右键点击扩展弹窗
2. 选择"检查"（打开开发者工具）
3. 查看 Console 标签页中的错误信息

### 没有书签显示
- 确保浏览器中有保存的书签
- 检查是否授予了 bookmarks 权限
- 打开开发者工具查看错误信息

### 图标无法显示
- 确认偏好设置中的“在线网站图标”已开启
- 检查网络能否访问 Google Favicon 服务；加载失败时会自动显示占位图标
