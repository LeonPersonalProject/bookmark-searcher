# 📚 书签搜索器 - 浏览器扩展

一个简洁高效的浏览器扩展，帮助你快速搜索和访问浏览器书签。采用现代化的毛玻璃设计风格，支持完整的键盘导航和文件夹浏览功能。

## ✨ 功能特点

### 核心功能
- 🔍 **实时搜索**：输入关键词即时过滤书签
- 🎯 **智能匹配**：同时搜索书签标题和 URL
- 💡 **高亮显示**：匹配的关键词会被高亮标记
- ⚡ **快速访问**：点击结果即可在新标签页打开
- 📁 **路径显示**：显示书签所在的文件夹位置

### 文件夹导航
- 📂 **浏览文件夹**：点击文件夹进入，查看内部书签
- 🔙 **返回导航**：支持返回上一级文件夹
- 🎨 **视觉区分**：文件夹使用金黄色背景，一眼识别
- 📊 **书签计数**：显示每个文件夹包含的书签数量
- 🔍 **文件夹搜索**：搜索时同时显示匹配的文件夹

### 键盘快捷键
- ⌨️ **完整键盘导航**：无需鼠标即可完成所有操作
- ↑↓ **方向键导航**：上下选择书签/文件夹
- ⏎ **Enter 打开**：打开选中的书签或进入文件夹
- ⎋ **Esc 清空**：清空搜索框，重置搜索
- ⇥ **Tab 导航**：Tab/Shift+Tab 切换选择

### 设计特色
- 🎨 **毛玻璃风格**：现代化的 Glassmorphism 设计
- 🌈 **淡雅配色**：朴素的浅灰蓝色系，干净清爽
- ✨ **流畅动画**：平滑的过渡和悬停效果
- 📱 **响应式设计**：自适应布局，体验流畅

## 📦 安装方法

### Chrome / Edge / 其他 Chromium 浏览器

1. **打开扩展管理页面**
   - Chrome: 访问 `chrome://extensions/`
   - Edge: 访问 `edge://extensions/`

2. **开启开发者模式**
   - 点击右上角的"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择本项目文件夹 `bookmark-searcher`

4. **完成安装**
   - 扩展安装完成！点击浏览器工具栏中的扩展图标即可使用
   - 建议将扩展固定到工具栏（右键点击扩展图标 → 固定）

### 重新加载扩展

如果更新了代码，需要刷新扩展：
1. 打开扩展管理页面
2. 找到"书签搜索器"扩展
3. 点击刷新图标 🔄

## 🎯 使用指南

### 基础操作

1. **打开扩展**
   - 点击浏览器工具栏中的扩展图标

2. **搜索书签**
   - 在搜索框中输入关键词
   - 实时查看匹配的书签列表
   - 匹配的关键词会高亮显示

3. **打开书签**
   - 点击任意书签在新标签页中打开
   - 或按 Enter 键打开第一个/选中的结果

### 文件夹导航

1. **识别文件夹**
   - 文件夹带有 📁 图标
   - 使用金黄色背景
   - 显示包含的书签数量

2. **进入文件夹**
   - 点击文件夹或选中后按 Enter
   - 只显示该文件夹内的内容

3. **返回上一级**
   - 点击左上角的"← 返回"按钮
   - 当前路径显示在导航栏

4. **文件夹内搜索**
   - 进入文件夹后输入关键词
   - 只搜索当前文件夹内的书签

### 键盘快捷键详解

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **↓** (下箭头) | 选择下一个 | 循环导航，到底部后回到顶部 |
| **↑** (上箭头) | 选择上一个 | 循环导航，到顶部后回到底部 |
| **Tab** | 选择下一个 | 与下箭头功能相同 |
| **Shift + Tab** | 选择上一个 | 与上箭头功能相同 |
| **Enter** | 打开/进入 | 打开书签或进入文件夹 |
| **Esc** | 清空搜索 | 重置搜索，显示所有内容 |

### 使用场景示例

**场景 1：快速搜索并打开**
```
1. 输入关键词（如 "github"）
2. 按 Tab 或 ↓ 选择想要的书签
3. 按 Enter 打开
```

**场景 2：浏览文件夹**
```
1. 找到目标文件夹（金黄色）
2. 点击或按 Enter 进入
3. 浏览文件夹内的书签
4. 点击"返回"按钮回到上一级
```

**场景 3：文件夹内搜索**
```
1. 进入某个文件夹
2. 输入关键词搜索
3. 只显示当前文件夹内的匹配结果
```

**场景 4：快速打开第一个结果**
```
1. 输入关键词
2. 直接按 Enter（自动打开第一个匹配的书签）
```

## 🔧 技术实现

### 技术栈
- **HTML5**：页面结构
- **CSS3**：样式和动画（Glassmorphism 毛玻璃效果）
- **JavaScript (ES6+)**：核心逻辑
- **Chrome Extensions API**：书签访问和标签页管理

### 核心功能实现

**书签管理**
- 使用 `chrome.bookmarks.getTree()` 获取书签树
- 递归遍历书签树，扁平化处理
- 区分书签和文件夹，分别处理

**搜索功能**
- 实时监听输入框变化
- 同时匹配标题和 URL
- 正则表达式高亮匹配文本

**键盘导航**
- 全局变量 `selectedIndex` 追踪选中状态
- 监听 `keydown` 事件处理快捷键
- 使用 `scrollIntoView` 实现自动滚动
- 模运算实现循环导航

**文件夹导航**
- 维护 `currentFolderId` 追踪当前位置
- 动态过滤显示当前文件夹内容
- 导航栈管理返回功能

## ❓ 常见问题

### 扩展无法加载
- 确保文件夹路径正确
- 确保所有文件都在同一个文件夹中
- 检查 manifest.json 是否有语法错误

### 页面显示空白
1. 右键点击扩展弹窗
2. 选择"检查"（打开开发者工具）
3. 查看 Console 标签页中的错误信息

### 没有书签显示
- 确保浏览器中有保存的书签
- 检查是否授予了 bookmarks 权限
- 打开开发者工具查看错误信息

### 图标无法显示
- 确保 `icons/` 目录中有 PNG 格式的图标文件
- 使用 `generate-icons.html` 生成图标
- 重新加载扩展
