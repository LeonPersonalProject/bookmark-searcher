# 书签搜索器 - 浏览器扩展

一个简洁高效的浏览器扩展，帮助你快速搜索和访问浏览器书签。

## 功能特点

- ✨ **实时搜索**：输入关键词即时过滤书签
- 🔍 **智能匹配**：同时搜索书签标题和 URL
- 🎨 **美观界面**：现代化设计，简洁易用
- ⚡ **快速访问**：点击结果即可在新标签页打开
- 📁 **路径显示**：显示书签所在的文件夹位置
- 🎯 **高亮显示**：匹配的关键词会被高亮标记

## 安装方法

### Chrome / Edge / 其他 Chromium 浏览器

1. 打开浏览器，进入扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

2. 开启右上角的"开发者模式"

3. 点击"加载已解压的扩展程序"

4. 选择本项目文件夹 `bookmark-searcher`

5. 扩展安装完成！点击浏览器工具栏中的扩展图标即可使用

## 文件结构

```
bookmark-searcher/
├── manifest.json      # 扩展配置文件（Manifest V3）
├── popup.html         # 弹出窗口的 HTML 结构
├── popup.css          # 弹出窗口的样式文件
├── popup.js           # 弹出窗口的逻辑代码
└── README.md          # 项目说明文档
```

## 文件说明

### 1. manifest.json
扩展的配置文件，定义了：
- 扩展的基本信息（名称、版本、描述）
- 所需权限（仅 `bookmarks` 权限）
- 弹出窗口的 HTML 文件路径
- 图标配置

### 2. popup.html
弹出窗口的 HTML 结构，包含：
- 标题区域
- 搜索输入框
- 统计信息显示
- 搜索结果列表容器
- 空状态提示

### 3. popup.css
弹出窗口的样式文件，实现了：
- 现代化的渐变背景
- 圆角搜索框设计
- 悬停动画效果
- 自定义滚动条样式
- 响应式布局

### 4. popup.js
弹出窗口的核心逻辑，实现了：
- 从浏览器加载所有书签
- 书签树的扁平化处理
- 实时搜索和过滤功能
- 关键词高亮显示
- 点击打开书签
- 键盘快捷键支持（Enter 键打开第一个结果）

## 使用方法

1. 点击浏览器工具栏中的扩展图标
2. 在搜索框中输入关键词
3. 实时查看匹配的书签列表
4. 点击任意书签即可在新标签页中打开
5. 按 Enter 键可快速打开第一个搜索结果

## 技术栈

- **HTML5**：页面结构
- **CSS3**：样式和动画
- **JavaScript (ES6+)**：核心逻辑
- **Chrome Extensions API**：书签访问和标签页管理

## 权限说明

本扩展仅申请了以下权限：
- `bookmarks`：读取浏览器书签数据

**注意**：本扩展不会收集、存储或上传任何用户数据。

## 关于图标

由于项目中未包含图标文件，你需要自行准备三个尺寸的图标：
- `icon16.png` (16x16 像素)
- `icon48.png` (48x48 像素)
- `icon128.png` (128x128 像素)

你可以：
1. 使用在线工具生成图标（如 favicon.io）
2. 使用设计软件创建自定义图标
3. 暂时删除 manifest.json 中的图标配置（扩展仍可正常工作）
