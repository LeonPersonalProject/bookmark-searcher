# 📚 书签搜索器 - 浏览器扩展

一个简洁高效的浏览器扩展，帮助你快速搜索和访问浏览器书签。采用高密度命令面板式界面，支持完整的键盘导航、文件夹浏览和多种主题模式。

## ✨ 功能特点

### 核心功能
- 🔍 **实时搜索**：输入关键词即时过滤书签（支持防抖优化）
- 🎯 **智能匹配**：同时搜索书签标题和 URL
- 🔤 **模糊搜索**：支持模糊匹配，更容易找到目标书签
- 💡 **高亮显示**：匹配的关键词会被高亮标记
- ⚡ **快速访问**：点击结果即可在新标签页打开
- 📁 **路径显示**：显示书签所在的文件夹位置
- 🎨 **Favicon 显示**：显示网站图标，更易识别

### 文件夹导航
- 📂 **浏览文件夹**：点击文件夹进入，查看内部书签
- 🔙 **返回导航**：支持返回上一级文件夹
- 🎨 **视觉区分**：文件夹使用暖色图标和数量标识，一眼识别
- 📊 **书签计数**：显示每个文件夹包含的书签数量
- 🔍 **文件夹搜索**：搜索时同时显示匹配的文件夹

### 智能功能 🆕
- ⏱️ **最近访问**：记录并快速访问最近打开的书签
- 🕐 **搜索历史**：保存搜索记录，快速重复搜索
- 💾 **数据持久化**：自动保存用户偏好和历史记录
- ⚡ **搜索缓存**：缓存搜索结果，提升响应速度

### 键盘快捷键
- ⌨️ **完整键盘导航**：无需鼠标即可完成所有操作
- ⌨️ **全局快捷键**：Ctrl/Cmd+Shift+K 快速打开扩展
- ↑↓ **方向键导航**：上下选择书签/文件夹
- ⏎ **Enter 打开**：打开选中的书签或进入文件夹
- ⎋ **Esc 分级返回**：关闭浮层、清空搜索或返回上一级
- ⇥ **Tab 导航**：按浏览器标准顺序切换交互控件

### 设计特色
- 🎨 **命令面板布局**：突出搜索操作，并用紧凑列表提高信息密度
- 🌙 **外观模式**：支持跟随系统、浅色和深色模式
- 🍬 **六套配色**：经典紫、糖果色、海盐蓝、抹茶绿、日落橙和黑白灰，可与外观模式自由组合
- 🌈 **语义化配色**：紫色表示焦点，暖色用于文件夹，状态更加清晰
- ✨ **克制动效**：选中和悬停不再引起列表位移，并支持减少动态效果
- 🧭 **路径导航**：通过可点击的面包屑快速返回任意上级目录
- ⚙️ **设置抽屉**：在保留搜索上下文的同时调整偏好

糖果色主题以草莓粉、葡萄紫和薄荷绿为主色；所有配色均提供独立的浅色与深色版本，并会自动保存选择。

### 用户体验
- 🦴 **骨架屏**：加载时显示优雅的骨架屏动画 🆕
- 💬 **错误提示**：友好的错误提示和反馈 🆕
- 💡 **快捷键提示**：在底部持续显示常用操作
- ♿ **无障碍支持**：完整的 ARIA 标签支持 🆕

## 📦 安装方法

### Chrome / Edge / 其他 Chromium 浏览器

1. **打开扩展管理页面**
   - Chrome: 访问 `chrome://extensions/`
   - Edge: 访问 `edge://extensions/`

2. **开启开发者模式**
   - 点击右上角的"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择本项目文件夹 `bookmark-searcher`

4. **完成安装**
   - 扩展安装完成！点击浏览器工具栏中的扩展图标即可使用
   - 建议将扩展固定到工具栏（右键点击扩展图标 → 固定）

### 重新加载扩展

如果更新了代码，需要刷新扩展：
1. 打开扩展管理页面
2. 找到"书签搜索器"扩展
3. 点击刷新图标 🔄

## 🎯 使用指南

### 基础操作

1. **打开扩展**
   - 点击浏览器工具栏中的扩展图标

2. **搜索书签**
   - 在搜索框中输入关键词
   - 实时查看匹配的书签列表
   - 匹配的关键词会高亮显示

3. **打开书签**
   - 点击任意书签在新标签页中打开
   - 或按 Enter 键打开第一个/选中的结果

### 文件夹导航

1. **识别文件夹**
   - 文件夹带有暖色文件夹图标
   - 右侧显示其中包含的书签数量
   - 显示包含的书签数量

2. **进入文件夹**
   - 点击文件夹或选中后按 Enter
   - 只显示该文件夹内的内容

3. **返回上一级**
   - 点击顶部路径中的任意上级目录
   - 或在搜索框为空时按 Esc 返回上一级

4. **文件夹内搜索**
   - 进入文件夹后输入关键词
   - 只搜索当前文件夹内的书签

### 键盘快捷键详解

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **↓** (下箭头) | 选择下一个 | 循环导航，到底部后回到顶部 |
| **↑** (上箭头) | 选择上一个 | 循环导航，到顶部后回到底部 |
| **Tab** | 下一个控件 | 按标准焦点顺序切换交互控件 |
| **Shift + Tab** | 上一个控件 | 反向切换交互控件 |
| **Enter** | 打开/进入 | 打开书签或进入文件夹 |
| **Esc** | 分级返回 | 依次关闭浮层、清空搜索、返回上一级或关闭弹窗 |

### 使用场景示例

**场景 1：快速搜索并打开**
```
1. 输入关键词（如 "github"）
2. 按 ↓ 选择想要的书签
3. 按 Enter 打开
```

**场景 2：浏览文件夹**
```
1. 找到带暖色图标的目标文件夹
2. 点击或按 Enter 进入
3. 浏览文件夹内的书签
4. 点击面包屑或按 Esc 回到上一级
```

**场景 3：文件夹内搜索**
```
1. 进入某个文件夹
2. 输入关键词搜索
3. 只显示当前文件夹内的匹配结果
```

**场景 4：快速打开第一个结果**
```
1. 输入关键词
2. 直接按 Enter（自动打开第一个匹配的书签）
```

## 🔧 技术实现

### 技术栈
- **HTML5**：页面结构
- **CSS3**：主题变量、高密度列表布局和轻量动效
- **JavaScript (ES6+)**：核心逻辑
- **Chrome Extensions API**：书签访问和标签页管理

### 核心功能实现

**书签管理**
- 使用 `chrome.bookmarks.getTree()` 获取书签树
- 递归遍历书签树，扁平化处理
- 区分书签和文件夹，分别处理

**搜索功能**
- 实时监听输入框变化
- 同时匹配标题和 URL
- 正则表达式高亮匹配文本

**键盘导航**
- 全局变量 `selectedIndex` 追踪选中状态
- 监听 `keydown` 事件处理快捷键
- 使用 `scrollIntoView` 实现自动滚动
- 模运算实现循环导航

**文件夹导航**
- 维护 `currentFolderId` 追踪当前位置
- 动态过滤显示当前文件夹内容
- 根据文件夹父子关系生成可点击的面包屑导航

## ❓ 常见问题

### 扩展无法加载
- 确保文件夹路径正确
- 确保所有文件都在同一个文件夹中
- 检查 manifest.json 是否有语法错误

### 页面显示空白
1. 右键点击扩展弹窗
2. 选择"检查"（打开开发者工具）
3. 查看 Console 标签页中的错误信息

### 没有书签显示
- 确保浏览器中有保存的书签
- 检查是否授予了 bookmarks 权限
- 打开开发者工具查看错误信息

### 图标无法显示
- 确保 `icons/` 目录中有 PNG 格式的图标文件
- 使用 `generate-icons.html` 生成图标
- 重新加载扩展
